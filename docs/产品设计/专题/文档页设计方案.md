# 文档页设计方案

- **状态**：2026-11-16 第一版评审通过，第一期已实现，见第十七节和[更新记录](../../更新记录/2026-11-16-文档模块.md)
- **原型**：[文档页原型.html](../演示/文档页原型.html)。单个文件，直接在浏览器打开；左下角“标注”会给每个区域编号，并写出参考了哪个产品。
- **范围**：把项目里的“笔记”模块换成“文档”：页面结构、编辑器、页面管理、团队协作、AI、数据格式、同步、迁移和分期。每篇论文旁边的论文笔记保留不变，只写它和文档的衔接。

## 一、定位

**文档模块是项目里的团队知识库：飞书知识库的管理方式，加 Notion 式的块编辑器。**

现在的全局笔记是一条条平铺的 Markdown，适合个人随手记，不适合团队：没有层级，不能把组会纪要、实验记录、调研报告组织成一棵目录；两个人改同一篇时整篇冲突；不能插入论文、实验这类研究对象。换成文档后：

- **页面可以嵌套**：项目首页下面挂“组会纪要”“实验记录”“文献调研”，每个下面再挂具体页面，像飞书知识库的目录树。
- **内容由块组成**：段落、标题、列表、待办、表格、公式、代码、图片都是块，可以拖动、转换、复制链接；输入 `/` 插入任何块。
- **块认得研究对象**：论文、论文的某一页、实验运行、稿件、项目文件都能作为卡片插进来，点开直接跳到对应位置。
- **为团队设计**：随项目同步给成员，按项目角色决定能否编辑；两个人改同一页的不同段落能自动合并；评论、@、历史版本、实时协同分期加入。

**论文笔记不变**：每篇 PDF 旁边的 `.notes.md` 仍在文献页的阅读器里写。它是“读这篇论文时的随手记”，和论文文件放在一起；文档是“整理过、给团队看的内容”。文档里可以插入论文笔记卡片，引用它的内容。

## 五、侧边视图（页面管理）

- **顶部**：搜索框（标题和正文，结果高亮）；“新建”按钮，下拉里有“新建页面、从模板新建、导入 Markdown”。
- **最近**：最近打开的 5 页，可以收起。
- **收藏**：星标的页面，可以拖动排序。
- **页面树**：
  - 无限层级，每层按拖动的顺序；展开状态记在本机；
  - 悬停时右侧出现“+”（新建子页面）和“⋯”；
  - “⋯”菜单：新建子页面、重命名、复制链接、创建副本、移动到…、收藏、导出、删除；
  - 拖动：放在两页之间是排序，放在页面上是变成它的子页面；
  - 页面左侧显示图标（没有设置时是文件图标）。
- **底部**：模板、回收站。回收站保留 30 天，可以恢复和彻底删除，和现在的笔记回收站一致。删除一页时连同它的子页面一起进回收站，恢复时一起回来。

## 六、文档页

**顶栏**：

- 面包屑：项目首页 / 组会纪要 / 11 月 16 日组会，每级可点；
- 编辑状态：“已保存”“正在同步”“1 分钟前 尾号 6018 编辑”；
- 协作者头像：最近编辑过这页的成员（第三期实时协同后是正在看的人）；
- 分享（团队项目）：成员列表和角色，邀请成员；复制页面链接（打开 Capsio 后定位到这页）；
- 更多：页面宽度（标准、全宽）、导出（Markdown、PDF）、历史记录（第二期）、移动到、创建副本、删除。

**标题区**：鼠标移上去出现“添加图标”“添加封面”；图标是表情符号；封面是图片，可以拖动调位置（第二期）。

**空页面**：标题下列出模板（空白、组会纪要、实验记录、论文调研、周报），点一下填入内容。

## 七、编辑器

**块类型（第一期）**：

| 分类 | 块                                                                               | Markdown 快捷输入           |
| ---- | -------------------------------------------------------------------------------- | --------------------------- |
| 基础 | 正文、标题 1–3、无序列表、有序列表、待办、引用、高亮块（带表情的提示框）、分割线 | `#` `-` `1.` `[]` `>` `---` |
| 结构 | 折叠块（点三角展开）、表格（可加行列、表头、拖动列宽）、两栏（第二期）           | —                           |
| 技术 | 代码块（语言选择、高亮、复制）、公式块（KaTeX）、行内公式                        | ` ``` ` `$$` `$…$`          |
| 媒体 | 图片（粘贴、拖入、调宽度、加说明）、文件附件、网页链接卡片                       | 粘贴网址时询问“转成卡片”    |
| 链接 | 链接到页面（`[[` 或 `@` 选页面）、子页面块（在正文里新建子页面）                 | `[[`                        |
| 研究 | 论文、论文页码引用、论文笔记、实验运行、稿件、项目文件，见第八节                 | `/论文` 等                  |

**操作**：

- **斜杠菜单**：输入 `/` 弹出，按分类列出全部块，支持中文和拼音首字母搜索（`/bg` 找到“表格”）；
- **块手柄**：鼠标移到块左侧出现“⋮⋮”，拖动可以移动；点击打开菜单：转换成、颜色、复制、创建副本、复制块链接、删除、评论（第二期）；
- **浮动工具栏**：选中文字后出现：转换、加粗、斜体、删除线、行内代码、链接、文字颜色和背景色、评论（第二期）、问 AI；
- **@**：@成员（团队项目）、@页面、@日期；
- **快捷键**：Ctrl+B/I/U、Ctrl+E 行内代码、Ctrl+K 链接、Tab 和 Shift+Tab 缩进、Ctrl+Shift+↑↓ 移动块、Ctrl+D 创建副本、Ctrl+Alt+1/2/3 标题、Ctrl+Enter 勾选待办；
- **粘贴**：从网页、Word、飞书、Markdown 粘贴时保留结构；粘贴图片存进文档的附件；
- **撤销**：Ctrl+Z、Ctrl+Shift+Z，每页独立。

## 八、研究块

文档和其他模块的衔接都在这里，这是和通用文档工具不一样的地方。

| 块           | 怎么插入                                        | 显示                                             | 点击后                         |
| ------------ | ----------------------------------------------- | ------------------------------------------------ | ------------------------------ |
| 论文         | `/论文`，按标题、作者搜文献库；或从文献页拖进来 | 标题、作者、年份、会议；有论文笔记时显示一行摘要 | 在文献页打开这篇论文           |
| 论文页码引用 | 在阅读器选中文字 → “引用到文档” → 选页面        | 引用的原文、论文名和页码                         | 打开论文并跳到那一页，高亮原文 |
| 论文笔记     | `/论文笔记`，选一篇论文                         | 论文笔记的内容（只读，随原笔记更新）             | 在文献页打开论文和笔记         |
| 实验运行     | `/实验运行`，选实验和运行                       | 运行名、状态、开始时间、参数、主要指标           | 打开实验页的运行记录           |
| 稿件         | `/稿件`                                         | 稿件名、最近一次编译结果、页数                   | 打开写作页的这篇稿件           |
| 项目文件     | `/文件`，或从实验页文件树拖进来                 | 文件名和路径；图片直接显示；CSV 显示前几行       | 在实验页打开这个文件           |

研究块只存对象的标识（论文 id、运行 id、相对路径），显示时实时读取，所以论文改名、运行结束后卡片自动更新；对象不存在时显示“已删除或不在这台电脑上”。

## 九、团队协作

| 能力     | 第一期                                                                                                             | 之后                                                        |
| -------- | ------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------- |
| 权限     | 跟项目角色走：所有者和编辑者可编辑；审阅者只读，第二期起可以评论；只读成员只读                                     | 第三期：单页权限（只给某些人看、某页只读）、对外分享链接    |
| 同步     | 随项目自动同步，和文献、实验一样不需要手动操作                                                                     | —                                                           |
| 同时修改 | 同步时按块合并：两人改不同块都保留；改同一块时保留后同步的一方，另一方的内容作为“冲突”高亮块插在旁边，提示人工处理 | 第三期：实时协同编辑（光标、在线头像），从根本上避免冲突    |
| 谁改的   | 每页记录创建人、最后编辑人和时间                                                                                   | 第二期：块级“谁改的”（悬停显示）                            |
| 评论和 @ | —                                                                                                                  | 第二期：选中文字或整块评论，回复、解决；@成员后对方收到通知 |

成员显示：账号目前只有手机号，显示“尾号 6018”。第二期在账号里加“昵称”，服务端存储，成员列表和文档都显示昵称。

## 十、AI

- **AI 助手能读写文档**：笔记的四个工具换成文档工具：
  - `capsio_list_docs`：页面树（标题、id、父页面、更新时间）；
  - `capsio_read_doc`：读一页，返回 Markdown（每块带 id）和版本号；
  - `capsio_create_doc`：在指定父页面下新建一页，内容用 Markdown；
  - `capsio_update_doc`：按块替换、插入、删除，或整页追加，必须带读到的版本号；
  - 写入规则和现在的笔记一致：询问模式下先审批，完全允许模式直接写。
- **页面上下文**：在文档页提问时，AI 拿到当前页面的标题、路径和选中的块；在 `<capsio-workspace>` 位置信息里列出文档页面树的前几层。
- **问 AI**：浮动工具栏的“问 AI”把选中内容带到右侧 AI 助手；第二期加文档内的“续写、改写、翻译、总结”，结果以建议的形式插入，确认后替换。

## 十一、数据格式

**每页一个 JSON 文件**，放在数据目录 `workspace/docs/<项目>/<页面 id>.json`，不再塞进 `workspace.json`（它现在已经 6.6 MB，所有笔记和对话都在里面，每次保存都整个重写）。

```json
{
  "schema": 1,
  "id": "6b1f…",
  "title": "11 月 16 日组会",
  "icon": "📝",
  "cover": null,
  "parent": "2c9a…",
  "order": "a1",
  "createdAt": "2026-11-16T10:00:00Z",
  "createdBy": "user-id",
  "updatedAt": "2026-11-16T10:30:00Z",
  "updatedBy": "user-id",
  "deletedAt": null,
  "width": "standard",
  "blocks": [
    { "id": "b1", "type": "heading", "props": { "level": 2 }, "content": [{ "text": "结论" }] },
    {
      "id": "b2",
      "type": "todo",
      "props": { "checked": false },
      "content": [{ "text": "补充消融实验 " }, { "type": "mention", "user": "user-id" }]
    },
    { "id": "b3", "type": "paper", "props": { "paper": "paper-id" } },
    {
      "id": "b4",
      "type": "image",
      "props": { "asset": "docs/9f2e….png", "width": 0.8 },
      "caption": []
    },
    { "id": "b5", "type": "toggle", "content": [{ "text": "原始数据" }], "children": [] }
  ]
}
```

- **块**：`id`（页面内唯一，随机生成，复制块时换新）、`type`、`props`（每种块自己的属性）、`content`（行内文字：`text` 加 `marks`，如加粗、颜色、链接；或行内对象：@成员、@页面、行内公式）、`children`（列表嵌套、折叠块里面的块）。
- **页面层级**：每页只记自己的 `parent` 和 `order`。`order` 是分数索引（两个字符串之间总能插一个新的），移动一页只改这一页的文件，两个人同时移动不同页面不会冲突。
- **图片和附件**：存到 `workspace/note-assets/<项目>/docs/`，文件名是内容哈希，块里只存相对路径；和现在笔记的图片同一个目录，已经随项目同步。
- **本机状态**：收藏、最近、展开的目录、页面宽度偏好存在本机，不同步（第二期收藏随账号同步）。
- **评论**（第二期）：单独的 `<页面 id>.comments.json`，和正文分开，评论不会和正文冲突。
- **版本号**：读写接口用文件内容的哈希做版本号，写入时版本不符就拒绝，避免覆盖别人或 AI 刚写的内容。

## 十二、同步

- **新增同步类型 `doc`**：`workspace/docs/<项目>/` 下的页面文件，和现在的文献、代码、附件一样按文件同步。
- **按块合并**：同步状态里留每页“上次和服务端一致的版本”（`base`）。本机和服务端都改了同一页时：
  - 页面属性（标题、图标、父页面、顺序）逐项合并，同一项都改了取服务端的；
  - 块按 id 合并：只有一方改的直接取；双方都改了同一块，保留服务端的，本机版本作为“冲突”高亮块插在它后面；一方删除、一方修改时保留修改；
  - 顺序以服务端为准，本机新加的块放回它原来的前一个块后面。
- **删除**：进回收站是写 `deletedAt`，像修改一样同步；30 天后彻底删除也同步。
- **页面树修复**：两个人同时把 A 移到 B 下、把 B 移到 A 下会形成环，读取时发现环就把其中一页放回顶层；父页面被删除的页面一起进回收站。

## 十三、迁移

- **全局笔记变成文档**：新版本第一次打开项目时，把每条未删除的笔记转成一页（Markdown 转成块），放在“项目首页”下的“笔记”页里，保留创建和修改时间；回收站里的笔记转成回收站里的页面。
- **原记录保留一个版本**：迁移后原笔记标记 `migratedTo`，不再显示；旧版本客户端同步过来的笔记修改会在下次打开时再迁移一次（追加为新版本）。确认所有设备都更新后再删除。
- **论文笔记不迁移**：仍是 PDF 旁边的 `.notes.md`。
- **右侧栏“笔记”**：改成“文档”：在任何页面都能打开一页文档并排写（例如一边读论文一边写调研），列表和搜索与侧边视图相同。
- **AI**：笔记工具换成文档工具；旧对话没有新工具，会提示新建对话（和之前论文工具升级的做法一样）。

## 十五、实现

**编辑器内核**：用 Tiptap（基于 ProseMirror，MIT 许可）。理由：

- 中文输入法、撤销、复制粘贴、跨块选择这些难点 ProseMirror 处理得最成熟，自己在 contentEditable 上写块编辑器很难做稳；
- Tiptap 只提供内核，界面全部自己画，可以和 Capsio 的设计规范一致（不像 BlockNote 自带一套 Mantine 或 shadcn 界面）；
- 第三期的实时协同可以直接接 Yjs（Tiptap 有现成的协同扩展）。

需要新增的依赖：`@tiptap/react`、`@tiptap/pm`、`@tiptap/starter-kit` 和表格、任务列表、图片、占位、拖动手柄等扩展，约 20 个包，构建后增加约 300 KB（压缩前）。现有的 KaTeX、remark（Markdown 解析，用于导入和迁移）继续使用。

**存储格式和编辑器格式分开**：磁盘上是第十一节的块格式，打开时转成编辑器文档，保存时转回来。这样以后换编辑器或加实时协同不影响已有数据。

| 部分     | 前端                                                                                                  | 后端（Rust）                                                                          |
| -------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 页面管理 | `src/workspaces/docs/`：DocsWorkspace（首页、文档页）、DocTree（侧边视图）、模板                      | `docs.rs`：列出、读、写（带版本号、原子写入）、移动、删除、恢复、彻底删除；页面树修复 |
| 编辑器   | `src/editor/doc/`：Tiptap 扩展（块 id、研究块、@、斜杠菜单、块手柄、浮动工具栏）、块格式 ↔ 编辑器格式 | —                                                                                     |
| 附件     | 粘贴和拖入图片、文件                                                                                  | 复用笔记附件的保存接口，路径改到 `docs/`                                              |
| 导入导出 | Markdown ↔ 块（remark）；PDF 用系统打印                                                               | 导出 Markdown 时把图片一起复制                                                        |
| 同步     | —                                                                                                     | `collaboration/sync.rs` 加 `doc` 类型和块级合并，`base` 存在同步状态目录              |
| AI       | 文档页发布上下文（页面、选中块）                                                                      | `agent/docs.rs`：四个文档工具，替换 `agent/notes.rs`                                  |
| 迁移     | 首次打开项目时把笔记转成页面                                                                          | —                                                                                     |
| 搜索     | 全局搜索的“笔记”改为“文档”，按标题和正文                                                              | —                                                                                     |
