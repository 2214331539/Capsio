# 0.5 体验打磨计划

整理日期：2026-11-21（0.4.0-alpha.7 发布之后）。0.4 把功能补齐了，0.5 的目标是让用起来像一个完整、成熟的产品：每次点击都有回应，每个区块各有分工，每个常用流程少一步。

## 现状和差距

| 方面 | 现在 | 成熟产品的做法 |
| --- | --- | --- |
| 按压反馈 | 按钮按下只换底色，标题栏右上角的按钮几乎没有反馈 | 按下轻微缩小、松开弹回；切换类按钮有明确的“开 / 关”状态 |
| 动效曲线 | `platform/motion.ts` 里八种场景用同一条曲线（ease-in-out），进出场一个节奏 | 进场减速、退场加速，小元素用带一点回弹的弹簧曲线 |
| 弹出层 | 菜单只有 3px 的淡入；对话框、提示气泡没有统一的出现方式 | 从触发位置放大淡入，关闭更快；提示气泡第一次有延迟，连续悬停不再等 |
| 状态变化 | 运行、编译、保存、连接等状态是文字直接替换 | 图标和颜色过渡（转圈 → 对勾 / 叉），结果停留片刻再淡出 |
| 列表和标签页 | 新增、关闭、拖动时内容直接跳 | 插入和移除有位移过渡，拖动有落点指示 |
| 操作确认 | 删除等操作多用确认框 | 能撤销的操作直接做，给“撤销”提示 |
| 加载 | “正在读取…”文字 | 骨架屏或进度，第一屏不空白 |

## 原则

1. **有回应**：鼠标移上、按下、处理中、完成，每一步在 100 毫秒内有反馈。
2. **有分寸**：动效 120–260 毫秒；打字、滚动这类高频动作不加动效；系统开了“减少动态效果”时全部关掉。只动 `transform` 和 `opacity`，不引起重排。
3. **少打扰**：能撤销的不弹确认；状态在原地显示，少用全局提示。
4. **一致**：同一种组件在所有页面行为一样，先在基础组件里做好，各页面直接受益。

## 分批计划

| 批次 | 内容 | 完成标准 | 估计 |
| --- | --- | --- | --- |
| **0 动效样张** | 做一张可交互的样张页（同 `界面打磨/方案.html` 的方式）：按钮按压、切换、菜单、对话框、标签页开关、状态变化各给“克制”和“活泼”两档手感 | 负责人选定手感和参数 | 1 天 |
| **1 基础组件** | 动效参数（时长分档、进场 / 退场 / 弹簧三条曲线）；按钮、图标按钮、切换、分段控件的按压和状态；菜单、弹出层、对话框、提示气泡的出现和消失；焦点框；减少动态效果 | 所有页面的按钮和弹出层自动换上新手感，测试通过 | 2–3 天 |
| **2 全局框架** | 标题栏右上角（浏览器、成员、通知、文档、AI 助手）、搜索和命令面板、侧栏、右侧栏、标签页、通知和提示 | 见下方“全局框架” | 3–4 天 |
| **3 文献与 AI 助手** | 用得最多的两块，见下方对应小节 | 读论文、问 AI 的完整流程逐步走查无卡顿、无跳动 | 4–5 天 |
| **4 文档、写作、实验、云主机** | 见下方对应小节 | 各模块的主要操作有状态过渡和反馈 | 4–5 天 |
| **5 流程和细节** | 撤销代替确认、快捷键一览、错误和离线提示、首次使用引导、夜间配色检查 | 见下方“流程” | 3 天 |

建议发版节奏：批次 0–2 合成 0.5.0-alpha.1，批次 3 为 alpha.2，批次 4 为 alpha.3，批次 5 为 alpha.4。每批先录屏给负责人看，确认后再合并。

## 1 基础组件

| 组件 | 要做的 |
| --- | --- |
| 按钮 / 图标按钮 | 按下缩到 0.93（图标按钮 0.82）、松开弹回；悬停底色 120 毫秒过渡；主按钮按下略暗；加载中按钮内显示转圈并保持宽度不变 |
| 切换按钮 | 标题栏里开关右侧栏、开关浏览器这类按钮，打开时有“按下”样式，状态切换有过渡 |
| 分段控件 | 选中底块在选项之间滑动，不是直接跳 |
| 菜单 / 弹出层 | 从触发点方向放大淡入（0.98 → 1），关闭比打开快；子菜单悬停有短延迟防误触；键盘上下移动时高亮跟随 |
| 对话框 | 放大淡入、背景渐暗；关闭时先淡出内容；多步对话框（新建项目）步骤之间左右滑动 |
| 提示气泡 | 第一次悬停 500 毫秒出现，之后连续悬停立即出现；气泡里写快捷键 |
| 输入框 | 聚焦时边框和焦点框过渡；校验失败轻微抖动一次并显示原因 |
| 动效参数 | `platform/motion.ts` 拆成进场、退场、两条弹簧（按的东西、出现的东西）曲线和按压、松开、滑动、浮层、退出几档时长；CSS 变量随之更新 |

## 2 全局框架

| 区块 | 要做的 |
| --- | --- |
| 标题栏右上角 | 五个按钮统一 28px、间距一致；按压回弹；右侧栏、浏览器打开时按钮保持按下样式；新通知时角标弹出一次；成员按钮显示协作者头像叠放；窄窗口时收进“更多” |
| 搜索 / 命令面板 | 打开放大淡入；最近打开和常用命令分组；每行显示快捷键；结果按类型分组，键盘移动平滑 |
| 侧栏 | 选中底块在模块之间滑动；收起 / 展开侧栏有宽度过渡；文献树、页面树展开折叠有高度过渡；项目切换菜单在项目多时带搜索 |
| 右侧栏 | 打开 / 收起滑入滑出；分段控件滑块；拖宽时显示宽度提示，双击缝恢复默认宽度；每个模块记住自己的宽度 |
| 标签页 | 打开从窄到宽展开、关闭收拢；拖动换位置有落点；中键关闭；标签多时两端渐隐，并有“全部标签”菜单；未保存圆点悬停变成关闭按钮 |
| 模块切换 | 内容区 100 毫秒淡入，保留每个模块的滚动位置和打开的标签 |
| 通知与提示 | 右下角统一提示：成功自动消失、出错停留，可带“撤销”“重试”；后台任务（翻译、导入、运行）在通知里显示进度 |

## 3 文献与 AI 助手

| 区块 | 要做的 |
| --- | --- |
| 文献列表 | 行悬停显示快捷操作；多选后底部出现批量操作条（移动、全文翻译、删除）；拖文件进来时整页高亮“松开导入”；导入进度卡片 |
| PDF 阅读 | 翻页、缩放平滑（触控板双指缩放）；划词工具条在选区旁淡入放大；高亮颜色选择有选中动画；批注气泡出现和关闭过渡；重新打开时提示“回到上次读到的第 N 页” |
| 全文翻译 | 译文标签上显示进度环；完成时淡入译文，不整页闪一下 |
| AI 回答 | 流式文字平滑出现，不让页面跳动；工具调用卡片展开收起有高度过渡；运行中的步骤有细微脉动；回答完成后操作按钮（复制、重新生成）悬停出现，点“复制”变成对勾 |
| 审批卡 | 出现时轻微强调；支持键盘（回车允许、Esc 拒绝）；处理后折叠成一行结果 |
| 输入框 | 发送按钮在生成时变成停止按钮（形状过渡）；输入框随内容平滑长高；附件加入和移除有过渡；拖文件进来时输入框高亮 |
| 小球形象 | 和真实状态挂钩：思考、执行命令、等待审批、完成、出错各有表情 |

## 4 文档、写作、实验、云主机

| 区块 | 要做的 |
| --- | --- |
| 文档 | `/` 菜单出现和键盘移动平滑；拖动块时显示插入线；页面树拖动换位有过渡；“已保存”在原地淡入淡出；封面和图标选择器有出现动画 |
| 写作 | 编译按钮状态过渡（编译 → 转圈 → 对勾或错误数）；新 PDF 和旧 PDF 交叉淡入，不闪白；点错误跳到源码时那一行闪一下 |
| 实验 | 运行按钮状态过渡（开始 → 运行中脉动 → 完成 / 失败）；运行日志自动跟随，离开底部时出现“回到最新”；建环境、装依赖显示步骤进度；源代码管理暂存 / 取消暂存时文件在两组之间移动 |
| 云主机 | 连接状态（连接中的点 → 已连接绿点）；断线时顶部提示并可一键重连；上传下载显示进度 |
| 项目中心 | 卡片悬停轻微抬起；新建项目步骤切换；归档后可撤销 |
| 设置 | 分类切换淡入；“测试连接”有进度和结果动画；保存在原地确认 |

## 5 流程

| 事项 | 要做的 |
| --- | --- |
| 撤销代替确认 | 关闭标签、移入回收站、删除批注、归档项目等可恢复的操作直接执行，提示里给“撤销”；只有删不回来的才确认 |
| 树里直接输入 | 文献、云主机等仍用对话框重命名的地方，改成在树里直接改名，和实验页一致 |
| 快捷键 | `?` 打开快捷键一览；Esc 在所有弹出层里行为一致；菜单项和提示气泡显示快捷键 |
| 错误和离线 | 错误提示写原因和下一步；离线时顶部一条提示，恢复后自动消失 |
| 首次使用 | 导览跟随新界面更新；示例项目（带一篇论文、一页文档）让新用户不配模型也能看懂 |
| 等待感 | 第一次加载用骨架屏；打开论文前鼠标悬停时预读；重命名、移动等操作先在界面上生效 |
| 夜间配色 | 新增的面板、阴影、提示条在夜间配色下逐一检查对比度 |

## 怎么验收

- 每批给出改前和改后的录屏（Playwright 录制），负责人确认手感后合并。
- 每个组件写进验收清单：悬停、按下、键盘、减少动态效果四种情况都检查。
- 动效只用 `transform` 和 `opacity`；在一般笔记本上滚动和打开面板保持流畅。
- 关键页面加截图对比测试，防止以后改动把样式改坏。

## 决定

| 事项 | 结论 |
| --- | --- |
| **手感** | 2026-11-21 看样张后选定：按钮等按的东西用“活泼”（按下 0.93、图标按钮 0.82、明显回弹），菜单、对话框、提示气泡等出现的东西用“克制”（从 0.97 放大淡入、几乎不回弹、关闭更快）。参数写在 `docs/UI-UX/03-交互与动效.md` |
| **撤销代替确认** | 同意（2026-11-21）：可恢复的操作直接做，提示里给“撤销” |
| **模块顺序** | 同意（2026-11-21）：先文献和 AI 助手，其次文档、写作、实验、云主机 |
| **新建和重命名** | 2026-11-21：新建文件、文件夹一律在边栏树里直接输入名字，和实验页一致，不弹对话框。云主机的新建已改；重命名放进批次 5 |
| **声音** | 建议不加 |
