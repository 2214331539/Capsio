# 交互与动效

版本：2.1 · 2026-11-22。适用 Projects / Workspace 两个窗口。参数来源：[motion.ts](../../src/platform/motion.ts)；场景控制：[view-transition.ts](../../src/platform/view-transition.ts)；样式：[motion.css](../../src/styles/motion.css)。2026-11-21 负责人在[动效样张](../产品设计/界面打磨/动效样张.html)里先选了按钮“活泼”、浮层“克制”；2026-11-22 觉得按钮抖动太明显，**全部改回“克制”**。

## 1. 统一原则

动画解释状态变化，不抢占研究内容。所有控件复用同一组变量，不在页面单独定义时长和曲线。

- **按的东西**（按钮、图标按钮、切换、分段控件）：按下轻微缩小，松开几乎不回弹；分段控件的选中底块滑过去。
- **出现的东西**（菜单、弹出层、对话框、提示气泡）：从触发处轻微放大淡入，几乎不回弹；关闭比打开快。
- 业务状态先更新；保存、删除、切换不等待动画结束。
- 页面在原位交叉淡化，旧画面托底；正文不位移、缩放或模糊。
- 不加循环装饰、波纹、逐项飞入。拖动、输入、光标、滚动、语言替换即时响应。

## 2. 参数

| Token | 值 | 用途 |
| --- | --- | --- |
| `--sf-motion-feedback` | 120ms | 悬停底色、边框 |
| `--sf-motion-press` / `release` | 90ms / 150ms | 按下缩小 / 松开复原 |
| `--sf-motion-selection` | 210ms | 分段控件、指示条滑动 |
| `--sf-motion-pop` | 210ms | 角标弹出 |
| `--sf-motion-content` | 220ms | 图标、树箭头、局部信息淡入 |
| `--sf-motion-navigation` | 320ms | 页面交叉淡化 |
| `--sf-motion-overlay` / `overlay-fade` | 210ms / 150ms | 浮层放大 / 淡入 |
| `--sf-motion-exit` | 90ms | 浮层退出 |
| `--sf-motion-panel` / `layout` | 240ms / 320ms | 辅助层透明度 / 布局反馈 |
| `--sf-ease-standard` | `cubic-bezier(0.42, 0, 0.58, 1)` | 页面交叉淡化 |
| `--sf-ease-enter` / `exit` | `cubic-bezier(0.2, 0, 0, 1)` / `cubic-bezier(0.4, 0, 1, 1)` | 进场减速 / 退场加速 |
| `--sf-ease-spring` | `cubic-bezier(0.25, 1.15, 0.5, 1)` | 按的东西（几乎不回弹，与 `pop` 相同） |
| `--sf-ease-pop` | `cubic-bezier(0.25, 1.15, 0.5, 1)` | 出现的东西（轻微回弹） |
| `--sf-pop-from` | 0.97 | 浮层起始大小 |

按下缩放：普通按钮 0.97，图标按钮 0.90；宽按钮最多缩 8px（`pressScale`）。提示气泡第一次悬停 500ms 出现，600ms 内移到下一个按钮立即出现。`applyAppearance` 在首次绘制前把参数装成 CSS 变量；JS 动画直接读 `motion.ts`。控件圆角 4px，菜单与弹窗圆角 8px。

## 3. 组件契约

| 场景                        | 行为与动效                                                                                                                                                                                                                                                 |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Button / 图标按钮 / 切换 | 120ms 悬停底色；按下即时加深并缩小，松开回弹（`installPress` 用 Web Animations 驱动 `scale`，不受页面自己的 transition 影响）；菜单项、disabled 不缩放。自定义按钮加 `data-press` 接入，`data-press="off"` 关闭                                                                                                                                                                                        |
| 工作区切页                  | React 状态即时提交；共享 ViewTransition 保留真实 DOM，320ms 交叉淡化，保持不透明底层。快速反向或转到第三页时从当前透明度与层级继续；退出层立即 inert / aria-hidden，完成后隐藏。原生网页在过渡期间隐藏，结束后由当前活动页恢复                             |
| 网格 / 列表                 | 同一选中底板移动；书架与实验管理内容使用同一 320ms 交叉淡化；点击当前模式不重放                                                                                                                                                                            |
| 亮暗切换                    | 根主题即时切换；太阳/月亮局部透明度与旋转 220ms；图标按钮无常驻底色                                                                                                                                                                                        |
| 语言                        | 即时替换界面文案；不重建编辑器或弹窗，不动画化全页尺寸                                                                                                                                                                                                     |
| Dropdown                    | 继续使用原生 select。支持 `appearance: base-select` 的 Chromium 使用统一 picker 皮肤、箭头旋转与进入/退出过渡；旧 WebView2 回退平台选择器，不影响功能                                                                                                      |
| 分段控件 | 组上加 `ref={segmentThumb}`，选中底块随 aria-pressed / aria-checked / aria-selected 滑动，首次定位不动画 |
| Menu | 使用共享 Menu；从打开点放大淡入（0.97 → 1，210ms），退出 90ms。退出立即 `inert` / `aria-hidden`，操作立即执行；快速重开取消旧清理计时，不保留第二份编辑会话                                                                                                    |
| Modal / 确认 / 文本输入弹窗 | 同一 HTML dialog、遮罩、尺寸规则；居中放大淡入 210ms。关闭与保存即时生效，原位留一份 inert 副本 90ms 淡出（不保留已卸载的表单）                                                                                                                                              |
| Tooltip | 第一次指针停留 500ms 后显示，600ms 内移到下一个按钮立即显示；键盘焦点立即提示；150ms 淡入；Escape 关闭 |
| 输入框 | 校验失败（aria-invalid）抖动一次，保留红色边框                                                                                                                                                                                           |
| TreeView                    | 同一个箭头旋转 220ms；子树立即可用，不逐项动画                                                                                                                                                                                                             |
| 实验详情 / AI 执行记录 | AI 执行记录和执行步骤用 `Collapse` 展开收起（高度过渡，内容保留）；实验详情仍用原生 details/summary；箭头旋转 220ms，支持键盘和可见焦点 |
| 提示条 | `components/feedback` 的 `toast` / `toastUndo` / `toastError`：底部居中，成功 4 秒、带操作 6 秒后消失，出错停留；悬停暂停计时。能恢复的操作直接执行并给“撤销”，只有删不回来的才确认 |
| 标签页 | `DocumentTabs`：新开的升起，关闭的原地淡出、其余用弹簧滑过去；拖动换位（`onReorder`）、中键关闭；放不下时两端渐隐并给“全部标签页”菜单 |
| 状态按钮 | `StateLabel` 叠放各状态文字，按钮宽度不变；运行中用 `sf-pulse-dot`，跳转到的行用 `sf-flash` 闪一次；首次加载用 `Skeleton` |
| AI / 笔记辅助栏             | 共用固定顶栏；选中下划线移动 220ms，保留的内容层淡化 240ms。退出层立即 inert / aria-hidden；不卸载会话、不重置滚动位置、不对正文位移或缩放。开关与宽度立即生效，避免 PDF/CodeMirror 连续重排。笔记进入或离开中央区时加入页面切换控制器，始终使用同一编辑器 |
| PDF / 代码 / 笔记           | 一级工作区与代码/实验管理/Git/运行记录切换保留编辑实例；文件或 PDF 标签仍由原编辑会话管理，不为动效复制第二份正文                                                                                                                                          |
| 窗口交接 / 文件选择器       | 继续由 Windows / Tauri 管理；不为原生系统对话框注入网页皮肤                                                                                                                                                                                                |

全站自定义确认和文本输入使用 [prompts.tsx](../../src/components/prompts.tsx)；脏表单确认由 Modal 内的同款嵌套对话框负责。网页退出的 `beforeunload` 提示仍由浏览器负责。

## 4. 焦点与中断

- 菜单支持方向键、Home / End；跳过禁用项。Escape / Tab 关闭并恢复触发点；点外部让目标接收焦点，不抢回原按钮。
- 右键和 Shift+F10 使用相同菜单；浮层根据视口边缘限制位置，内部可滚动。页面滚动、窗口失焦或大小变化时关闭。
- 菜单打开即隐藏原生文献网页，继续使用 `data-native-overlay` 协议；菜单退出不留下透明点击层。
- Modal 保留焦点圈定、Escape 和 busy / dirty 保护；点击遮罩与关闭按钮走相同保护，拖拽释放不误判为点遮罩。
- 原生窗口连续关闭请求合并处理；等待确认期间不重复提交退出。保存失败保留表单和错误，允许重试。
- 异步操作显示真实 pending / error；不为“播完动画”延迟成功，不伪造进度，不清空草稿。

## 5. 减少动态效果与性能

`prefers-reduced-motion: reduce` 禁用 transition、animation 和平滑滚动，包括 dialog backdrop、select picker 与箭头伪元素。页面直接切换；按压缩放和对话框淡出副本不执行；运行中开启减少动态效果时立即收敛到最新目标。菜单即时退出，业务防抖与 Tooltip 触发延迟保持。保存、任务和关闭保护不依赖动画完成。

禁止 `transition: all`、全页 blur、持续 will-change、逐帧写 store、宽高动画、对大量列表项的 stagger。切页只动画 opacity，结束或取消后释放临时合成提示。320ms 是动效长度，不是 FPS 或整站性能达标声明。缓存只覆盖访问过的视图；切换项目或重载数据时清理中央视图缓存，AI/笔记保持原有项目隔离机制。

## 6. 新功能接入

1. 从 Button / Input / Dropdown / Menu / Modal / Tooltip 组合交互；不要新写一套菜单皮肤。
2. 状态属于业务，浮层只处理位置、可见性、键盘和视觉保留。
3. 页面切换复用 [ViewTransition](../../src/components/workspace/ViewTransition.tsx)；列表模式使用 `sf-view-stack--flow` 保留内容的自然高度。全局快捷键、材料上下文和原生窗口显隐读取 `useActiveView`，隐藏页面不响应前台操作。
4. 按 [开发与验收](04-开发与验收.md) 检查快速操作、明暗、中英、焦点、失败恢复与 reduced motion。
