## 改了什么

- **按钮手感改回“克制”**：负责人觉得按钮抖动太明显。按下缩放从 0.93（图标按钮 0.82）改为 0.97（图标按钮 0.90），松开几乎不回弹，时长 90 / 150 毫秒；分段控件滑块、通知角标、标签页滑动用同一条几乎不回弹的曲线。
- **关闭标签页、删除页面不再抖动**：标签栏原来在每次重新渲染后，把位置变了的标签都滑过去，并给关掉的标签留一个淡出的影子；关闭一个标签，或者文献库刷新时标题宽度变化，会让好几个标签同时滑动。现在新标签只淡入，其他标签直接到位，只有拖动换位置后才滑动。文档页面树同理：只有拖放后才平滑归位，删除页面、展开收起时直接到位。
