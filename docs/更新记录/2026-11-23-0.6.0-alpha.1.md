## 改了什么

- **AI 可以在远程服务器上跑实验**：原来的指令要求训练、评估、测试都必须走正式运行（只在本机、断网），AI 因此拒绝通过 SSH 在服务器上启动训练。现在正式运行只是本机实验的首选；远程服务器（SSH、云主机、集群）和需要联网的操作直接用命令行，按当前权限审批（询问模式在聊天里批准，完全允许直接执行）。长任务放进 tmux 或 nohup，日志写文件，之后读日志汇报真实结果。
- **修复：点头像后设置等窗口打不开**（同事 Win10 上报）：设置、模型设置、账号、快捷键、关于这些弹窗打开前都要先等内置浏览器隐藏，而所有内置浏览器命令排在同一个队列里；只要有一条原生命令不返回，之后所有弹窗都打不开。现在弹窗最多等 0.4 秒，队列 1.5 秒后继续，卡住时上报错误。是哪条命令卡住还要看同事那台的错误上报确认。
- **一键卸载旧版**：旧版 Scientify 还装着时，第一次提示里和“设置 → 关于”里有“卸载旧版”。Windows 打开 Scientify 自带的卸载程序，由用户确认；Mac 把旧的 Scientify.app 移到废纸篓。数据还在旧版目录里时不给卸载，改为引导到“数据与备份”搬走数据。
- **Scientify 改名 Capsio**：应用名、安装目录、程序、包标识、更新地址、仓库（2214331539/Capsio）、服务器（服务、用户、目录、数据库、Nginx）都换成 Capsio。
- **老用户自动接上**：
  - 第一次打开时接管 Scientify 的数据：Windows 上旧安装目录旁的数据搬到新目录（跨盘时原地使用），改过位置的照原位置用；Mac 上从 `Application Support/Scientify` 搬过来；
  - 旧版的更新地址也写入同一份清单，装着 Scientify 的电脑会更新到 Capsio；
  - 旧对话里 `scientify_*` 工具照常可用，文档里的 `scientify://` 链接照常能打开，界面状态（阅读位置、布局等）带过来；
  - 服务器同时认旧版的版本头和改名前签发的登录凭证，用户不用重新登录；
  - 接好后提示一次“旧版 Scientify 可以卸载了”；数据还在旧版目录里时不提示。
- **没改名的**：项目文件夹里的 `.scientify` 隐藏目录、附件存储桶 `scientify-files`、Mac 自签名证书名、Mac 钥匙串里翻译密钥的条目名、服务端渠道密钥的加密盐。
- **项目封面换成浅底加产品彩色**：7 种颜色，书脊是颜色本身，封面是同色浅底、墨色文字；旧的暗色按顺序对应到新颜色。
- **AI 面板空状态**：按所在页面给 3 个起步问题，点一下放进输入框；还没选模型（或官方模型没登录）时给“用 Capsio 账号开始”和“用自己的模型”。
- **功能导览更新**：项目里的导览讲五个模块、边看边记和 AI 起步问题；看过旧导览的人会再看到一次。
- **后台目标**（0e416b3，首次发布）：AI 用 Codex 的目标功能在后台继续做没完成的任务，切换项目也不中断，做完在应用内通知；关闭窗口时有进行中的目标就收到托盘。

## 需要注意

- **Windows**：更新后 Capsio 装在新目录（默认 `%LOCALAPPDATA%\Capsio`），开始菜单出现 Capsio；旧的 Scientify 不会自动删除，按提示卸载即可。
- **Mac**：应用内更新会把新版装在原来的 `Scientify.app` 位置；想让名字也变，用新的 DMG 安装 Capsio，再把旧的拖进废纸篓。划词翻译要在“辅助功能”里重新允许 Capsio。
